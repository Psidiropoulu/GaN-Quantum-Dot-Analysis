\section{Height Analysis}

The height error is defined as

\[
e_h = h_{\mathrm{measured}} - h_{\mathrm{true}}.
\]

The mean absolute error is

\[
\mathrm{MAE} = \frac{1}{N}\sum_{i=1}^{N}|e_i|.
\]
